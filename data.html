Organizing and Analyzing Research Data

This lesson teaches students how to prepare raw data for analysing using Excel and PASW(SPSS).

It explains how to: "Format raw research data in an Excel spreadsheet for efficient analysis."

  • Format variables correctly
  • Convert categorial data into dichotomous values
  • Run descriptive statistics in Excel
  • Run inferential statistics such as Kurskal-Wallis
